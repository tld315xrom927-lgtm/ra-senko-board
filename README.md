# 選考進捗ボード（RA業務専用｜選考進捗管理アプリ）

自社が直接契約している企業への応募者の選考状況を、RA担当者がひと目で把握・更新するためのWebアプリです。

## 使い方（かんたん）

| やりたいこと | 操作 |
|---|---|
| 応募を登録する | 左上（スマホは右下の＋）の「新規応募登録」。必須は求職者名と企業名だけ。複数社まとめて登録OK |
| ステータスを変える | 一覧の「選考ステータス」のプルダウンをそのまま変更 |
| 日付や備考を直す | 一覧のマス目をクリック → 小さな入力欄で保存（空欄の「＋」も同じ） |
| 面接・オファー面談を登録 | 一覧の「面接日時」「オファー面談日時」のマスをクリック。一次・二次・最終と何回でも追加可 |
| CAへのリマインド | 「CAリマインド」の「未」を押すと「済」になる（トップの「要対応」の「済にする」でもOK） |
| 定期面談（内定承諾〜入社） | メニュー「定期面談」。次回面談日を入れると次の予定が自動で入る |
| 求職者の詳細 | 一覧の求職者名をクリック |
| 絞り込み | 上のカード（書類選考中・内定など）をクリック、または検索欄・プルダウン |
| 削除したものを戻す | 設定 → ゴミ箱 → 復元 |
| CSV・バックアップ | 設定 → バックアップ・CSV出力 |
| ダミーデータを消す | 設定 → テスト用ダミーデータ → 削除 |
| メンバーを追加 | （管理者のみ）設定 → 許可メンバー にメールアドレスと権限（管理者／メンバー）を登録。その人はGoogleでログインすれば使える |

色の意味：**赤＝至急（今日・期限切れ）／オレンジ＝明日・3日以内／黄＝1週間以内・注意**

## 構成

- 画面：素の HTML / CSS / JavaScript（ビルド不要）。`index.html` → `js/app.js`
- データ：Supabase（無料枠）。ログインは Google またはメール＋パスワード
  - `ra_members` に登録され、メール確認済みのアカウントだけがデータを読み書きできる（DBの行レベルセキュリティで制限）
  - 権限は「管理者」（メンバーの追加・変更・削除）と「メンバー」（データの閲覧・編集）。自分自身の降格・削除はできない
  - 変更はリアルタイムで他の端末に反映。オフライン中の変更は端末に保存され、つながったら送信
- 公開：GitHub Pages（`https://tld315xrom927-lgtm.github.io/ra-senko-board/`）
  - 公開されるのはプログラムだけ。データはログインした許可メンバーしか見られない
- `js/config.js` に Supabase の Project URL と Publishable（anon）key を書く（秘密鍵は書かない）

## ファイル

```
index.html          入口
css/style.css       デザイン
js/app.js           起動・画面切替・ログイン画面
js/store.js         端末内保存（IndexedDB）・ゴミ箱
js/cloud.js         Supabase 同期・ログイン・メンバー管理
js/model.js         ステータス・集計・要対応・カレンダーのルール
js/forms.js         入力フォーム（新規応募・応募詳細・予定・マスタ）
js/table.js         応募者一覧テーブル
js/dashboard.js     トップページ
js/calendar.js      カレンダー
js/pages.js         CA・求職者・企業・定期面談ページ
js/settings.js      設定（同期・メンバー・ステータス・CSV・ダミー・ゴミ箱）
js/demo.js          ダミーデータ
supabase/setup.sql  Supabase の初期設定SQL
serve.py / start.bat  このPCで動かす（http://localhost:8090）
```
